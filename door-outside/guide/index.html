这版到底验证什么

预言一定实现，但预言不规定解法。房里的手、听筒、电话线、门锁、饭桌、碗和椅子各自运行；玩家只能做真实动作，改变它们最后怎样接触、谁承受、碎片在哪里。

闪烁警告：内部测试默认启用高强度快速闪烁、震动和低频压迫声。右上角可随时关闭“极限闪烁”。

怎么操作

电脑：WASD / 方向键移动；靠近物品或建筑按 Enter/E；输入实际动作并回车。

手机：横屏；左下方向键移动，右下“说 / 操作”打开输入。

可说：拿起石块、向前扔石块、砸这里的墙、把回铃碎片装进玻璃罐、把碎片挂在墙上、推开最小椅子。不能说“预言取消”或“过去没发生”。

“状态链”显示所选物品的十个完整状态、八层状态塔和当前联合态；“对象图谱 60”列出二十件主物、四十件辅物及其故事作用。

第一段：电话夜

父亲没有回来。红电话线从开场就穿过墙内导轮和外侧锁舌，因此“听筒被夺走 → 线绷紧 → 锁舌进入门框”不是临时生成的灾难。

  1. 先看清回铃碎片、玻璃罐、石块、木杆和墙的位置。
  2. 靠近红电话触发第一段闪回。它只有紧张的音画侵入，不播放解释过去的录像。
  3. 预言从三条已写好的电话预言中选择一条，宣布后才取得未来信用。
  4. 物品链开始前进。你可以拿走碎片、装进罐子、改位置、打墙洞或制造承载物。
  5. 第一个满足“听筒强制出声、锁舌锁定、主门锁定”的世界状态完成预言。

主要分支：碎片由玩家携带、装入玻璃罐、建筑洞口成为来路、碎片被红线缠住、碎片仍留在房间。站进正在锁合的门框会当场失败。

第二段：饭桌夜

几年后，父亲只以空外套、鞋和钥匙声留下痕迹。母亲试图把饭局摆成完整家庭；离开的方向一确定，那只手、饭桌、桌布、碗和黑汤分别进入自己的链。

  1. 靠近最小椅子，触发第二段“狂怒”闪回。
  2. 预言只说饭桌向最小座位翻倒、黑汤越过孩子的位置，不要求玩家配合。
  3. 移动饭桌碎片、椅子、罐子或建筑局部，改变最后碰撞和可达性。
  4. 桌子 overturned、碗 spilling、黑汤 spread 时，状态判定器确认预言完成。

站在最小椅子的冲击区会被桌面当场压住。若两块碎片都不可达，且没有洞口或自由工具重新建立路径，系统可判定“已经无解”。

物品链、联合态、状态塔

六十件目录物品各有十个完整快照，包含坐标、局部坐标、朝向、速度、力、质量、碰撞形状、所有者、承载、容器、接触、连接、机构进度、材质、温度、声音和来源。手与听筒只在接触、握持、共同移动等指定步骤耦合；动态碰撞也会生成联合态。

墙、地板、天花板按局部块重建。任何命中坐标都能形成真实洞口；足够大的破坏会生成有独立碰撞和状态链的脱落片。第八层场景分支直接读取具体碎片状态、所有者和洞口，不计算“损坏率”。

失败与重来

身体进入明确冲击体时当场失败；具体物品状态使目标再无可达路线时判定无解。失败窗口说明是哪一个碰撞体或哪几件物品造成的，并允许从当前时间节点重来。

分享给别人时，本地模型怎么用

访问者不安装任何程序。打开 GitHub Pages 后，点“下载本地模型”，网页优先尝试 WebGPU 的 Qwen2.5 0.5B，失败则改用 CPU/WASM；模型保存在访问者自己的浏览器缓存。网页提供三个组件源并对单源超时自动换源。

模型负责把自然语言对齐到现有动作、从候选中选择触发预言、复核状态判定；它无权创造物品、改写状态或拼出预言专用链。未下载模型时，严格规则备用路径仍可完整玩。
